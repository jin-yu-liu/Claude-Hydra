### 问题修复

- 开启沙箱隔离（Windows）后，Claude Code 对项目的修改现在会直接写入真实磁盘。此前改动只留在沙箱副本里，真实项目没有变化，从其他账号导入的历史会话同样如此
  - Windows 与程序目录、AppData、用户目录下的点文件（如 `.gitconfig`、`.ssh`）、其他账号与 Hydra 的数据以及注册表的写入仍留在沙箱内
  - 已开启沙箱的账号需重启一次才会生效；此前留在沙箱里的改动不会自动搬回项目
- 本地中继的连接不再被 Hydra 同时启动的子进程（Claude、Mihomo、PowerShell）继承，避免连接在中继关闭后仍保持打开，或在该进程退出时被重置
