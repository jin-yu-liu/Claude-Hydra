### 问题修复

- 修复 macOS 开启沙箱隔离后 Claude 启动即崩溃的问题
  - Claude 现在以 `--no-sandbox` 运行在账号的 Seatbelt 沙盒内。macOS 不允许沙箱嵌套，因此 Chromium 自带的渲染进程沙箱会关闭，网页一旦被攻击，影响范围会比平时大
  - 绑定节点时，账号只能连接自己的本地中继，直连、其他本机端口、UDP 和系统 DNS 都会被拒绝
  - 账号不能读写其他账号的数据和 Hydra 配置，沙盒内的工具不能启动其他应用或写入开机启动项
  - 沙盒内的 Claude Code 需要浏览器登录时，请手动打开它给出的链接
- 修复 Windows 沙箱中未绑定节点的账号无法联网的问题，Claude Code 和 git 不再因 `ENOTFOUND` 反复重试
- 修复未检测到 Claude 时无法保存环境配置的问题，保存失败的提示也会滚动到可见位置

### 改进

- macOS 不再向 Claude 传入调试端口，Claude 窗口不再注入网页指纹，账号浏览器的指纹不受影响
- 更新 macOS 隔离说明，写明沙盒的能力边界
